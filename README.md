# csharp-learning
C# studies, exercises and small projects.

Repositório criado para registrar minha evolução nos estudos de C#.

Atualmente estou estudando através da formação **Foundational C# with Microsoft**, disponibilizada pelo freeCodeCamp em colaboração com a Microsoft.

Aqui pretendo armazenar exercícios, desafios e pequenos projetos desenvolvidos durante meus estudos, mantendo também um histórico da minha evolução com a linguagem.

## Conteúdos estudados

- Variáveis e tipos de dados
- Operadores
- Strings
- Arrays
- Estruturas de repetição
- `foreach`
- Métodos

## Objetivo

Mais do que apenas armazenar códigos, quero utilizar este repositório para acompanhar minha evolução, revisar conteúdos e colocar em prática os conceitos que estou aprendendo.
